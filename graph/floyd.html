Floyd 多源最短路

Floyd（Floyd–Warshall）算法用一个 O(n³) 的三层循环求出任意两点之间的最短距离——即多源最短路（All-Pairs Shortest Path）。它是一次纯粹的动态规划：状态是「允许哪些点作中转」，转移是「经不经这个中转点」，代码只有三行，还能直接处理负权边（只要没有负环）。

算法原理

状态定义（关键）

d[k][i][j] = 「只允许经过编号 ≤ k 的结点作为中转」时，i → j 的最短路径长度。最终答案 d[n][i][j] 允许一切中转点，就是真正的全源最短路。

考虑从 i 到 j 且中转点上限为 k 的最短路，只有两种可能：不经过 k（值即 d[k-1][i][j]），或者经过 k。由于除了 k 之外的中转点都 ≤ k−1，且最短路是简单路径，这条路的「i → k」段与「k → j」段各自也是「中转点 ≤ k−1」意义下的最短路，于是可以用 d[k-1][i][k] + d[k-1][k][j] 表示。取min 即得转移。因为第 k 层只依赖第 k−1 层，滚动掉第一维就成了常见的就地写法：

for i in 1..n:
    for j in 1..n:
        d[i][j] = (i = j ? 0 : 直接边权或 +∞)

for k in 1..n:                        // 中转点上界：必须放在最外层！
    for i in 1..n:
        for j in 1..n:
            d[i][j] = min(d[i][j], d[i][k] + d[k][j])

为什么 k 必须在最外层

正确性依赖一个不变式：进入第 k 轮时，矩阵里存的正是「中转点集合 ⊆ {1..k−1}」的最短路。只有把 k 放在最外层，一整轮才只引入「新允许的那个中转点 k」，且 d[i][k]、d[k][j] 本身在本轮内不会再被 k 改进（d[k][k]=0 且边权非负时它们不变），转移才是干净的。若把 k 写到内层，d[i][k] 可能已经被「比 k 更大的中转点」改进过，等于偷偷允许了尚未轮到的点作中转，结果会偏小或漏更新——除非你把 i、j、k 三个循环都跑满 n 遍，而那已经失去意义。这也是本页动画按「一层一整轮」推进的原因。

可重复贡献与传递闭包

Floyd 的本质是闭包运算：把 (min, +) 换成 (|, ×)（逻辑或、逻辑与），初始矩阵换成邻接矩阵（i→j 有边即 1，i=j 记 1），同样的三重循环就得到传递闭包——即「i 能否到达 j」。这就是 Warshall 算法。因为运算是「可重复贡献」的（x ⊗ x = x），中途被就地覆盖也不会出错。把内层的布尔矩阵按行存成 bitset，d[i][k] 为真时只需一次「整行或起来」，O(n³/64) 即可求出闭包，n 上千也还能跑。

// 传递闭包（Warshall）：可达记 1
for k in 1..n:
    for i in 1..n:
        if reach[i][k]:
            for j in 1..n:
                reach[i][j] |= reach[k][j]      // bitset 优化：reach[i] |= reach[k]
提示：什么时候选 Floyd

① n ≤ 400 量级且需要任意两点的答案（三角不等式校验、图中直径、"是否共圆/可达"判定、DP 转移里要频繁查两点距离）。跑 n 次堆优化 Dijkstra 是 O(n(n+m)\log n)，稀疏图上更快但拿不到「路径上经过哪些中转点」这一层信息。② 负权边可以直接处理（比 SPFA 更好写），只要先检查 d[i][i] < 0 判负环：跑完后对角线出现负数即说明 i 在某个负环上。③ 常用扩展：Floyd 求必经点（d[s][t] == d[s][u]+d[u][t] 则 u 在一条最短路上）、最小环（枚举 k 前用 d[i][j]+w[i][k]+w[k][j] 求经过 <k 的环）、倍增 Floyd（矩阵乘法 + 倍增求恰好/不超过 L 步最短路）。

复杂度分析

指标量级说明
时间O(n³)三层循环各 n 次；转移只有比较与加法，常数极小
空间O(n²)一个距离矩阵即可（就地滚动第一维）；要还原路径需额外 nxt[i][j]，仍是 O(n²)
适用规模n ≈ 400 以内（约 6×10⁷ 次基本操作）；n 更大而只需单源时改用 Dijkstra / SPFA
边权要求可有负权边；不得有负环（跑完后 d[i][i] < 0 即说明 i 在负环上）
传递闭包变体O(n³ / 64)把 + / min 换成 × / |（Warshall），行用 bitset 存储后按位或

应用与局限

应用：① 需要在图上频繁查询「两点最短距离」的题目（把图预处理成距离矩阵后查询 O(1)）；② 判定可达性 / 传递闭包（偏序关系的闭包、正则闭包、依赖关系推导）；③ 求图的直径、最小环、必经点；④ 差分/建图技巧中的「先 Floyd 补全三角不等式再 DP」（如最短路约束下的 TSP 预处理）；⑤ 倍增 Floyd——把转移写成 min-plus 矩阵乘法，用快速幂求「恰好走 L 步」的最短路。

局限：① O(n³) 对稀疏大图不可接受，n > 500 基本不能再用；② 存在负环时距离无定义，只能给出「负环上 d[i][i] < 0」的判定；③ 需要 O(n²) 的邻接矩阵存图，点编号必须先压缩到 1..n；④ 三层循环的访问顺序对缓存敏感，工程上常把 k 放最外层（本页写法）并考虑分块。
