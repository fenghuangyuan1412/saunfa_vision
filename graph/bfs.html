广度优先搜索

广度优先搜索（Breadth-First Search，BFS）从源点出发，借助队列逐层扩展：先访问距离为 d 的所有结点，才可能访问距离为 d+1 的结点。这一「层层推进」的性质使 BFS 在无权图上天然求出最短路。

算法原理

维护距离数组 dis[]：源点 dis=0，其余初始为 -1（未访问）。把源点入队并标记；每次出队一个格子，检查它的四个邻居：越界或障碍跳过，已访问（dis != -1）跳过，否则令 dis[邻居] = dis[当前] + 1 并入队。每个结点恰好入队一次、出队一次。

procedure BFS(s):
    for v in all cells: dis[v] = -1
    queue.clear()
    dis[s] = 0; queue.push(s)
    while queue not empty:
        u = queue.pop()               // 队头出队
        for v in neighbors(u):        // 下、右、上、左
            if v 越界 或 是障碍: continue
            if dis[v] != -1: continue  // 已进入过队列
            dis[v] = dis[u] + 1
            prev[v] = u                // 记录前驱，便于还原路径
            queue.push(v)

最短路性质：在无权图（网格中相邻即有边）上，BFS 首次把某结点加入队列时的 dis 值必为源点到它的最短距离。因为队列按距离非递减出队，任何更短的路径都会在更早的层被发现。

提示：无权图最短路 与 多源 BFS

① 求无权图单源最短路首选 BFS，dis[T] 即 S 到 T 的最短距离，沿 prev[] 回溯得到一条最短路径。② 把所有源点在开始时全部入队（dis 均置 0），就得到多源 BFS：仍然逐层扩展，求出的是「任一源点」到每个结点的最短距离，常用于多起点扩散、火源蔓延、01-棋盘距最近特殊格距离等问题。

复杂度分析

指标量级说明
时间复杂度（一般图）O(n + m)n 个结点、m 条边：每个点入队一次，每条边检查一次
时间复杂度（网格）O(RC)R×C 格，每格至多 4 个邻居，等价 O(点数+边数)
空间复杂度O(n + m)dis[]/prev[] 为 O(n)；队列最宽约一层结点数，网格上为 O(min(R, C)) 量级，图上界 O(n)
正确性仅适用于无权图（或边权相同）；带权图需用 Dijkstra 等算法

应用与局限

BFS 是迷宫最短路、连通分量划分、Flood fill（洪水填充，图像区域着色、扫雷展开）、拼图类（华容道、八数码，配合双向 BFS / BFS 全图预处理）等问题的标准工具，也是许多图论算法（如无权最短路、分层图）的骨架。局限：只适合无权（单位权）图；带负权或一般边权需 Dijkstra / SPFA；全图 BFS 需要存储整张图与队列，超大隐式状态空间时要配合哈希或双向搜索。
