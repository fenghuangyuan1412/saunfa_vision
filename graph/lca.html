最近公共祖先 LCA

最近公共祖先（Lowest Common Ancestor，LCA）是有根树上两点之间「第一次汇合」的那个祖先：给定结点 u、v，它们的 LCA 是同时为 u 与 v 的祖先（约定结点是自己和自己的祖先）且深度最大的结点。树上路径查询、树上差分、虚树、树的直径，几乎都从这里起步。

算法原理

先约定记号：root 为根，dep[v] 是 v 的深度（根为 0），fa[v] 是 v 的父结点（根的父结点记为 0／不存在）。

朴素做法：先对齐深度，再同步上跳

若 dep[u] > dep[v]，先把 u 一路上跳到与 v 同深；然后两者同时上跳，直到相遇，相遇点即 LCA。正确性来自一个单调事实：两条到根的路径一旦汇合，之后便完全重合，所以「第一次相等的位置」就是最深的公共祖先。每次只跳一级，代价 O(depth)，链状树上退化到 O(n)。

function lca_naive(u, v):
    while dep[u] > dep[v]: u = fa[u]        // 较深的 u 上跳
    while dep[v] > dep[u]: v = fa[v]        // 较深的 v 上跳
    while u ≠ v: u = fa[u]; v = fa[v]       // 同步上跳
    return u

树上倍增：一次跳 2^k 级

把「跳一级」换成「跳 2k 级」就能把线性变成对数。定义 fa[k][v] = v 向上 2k 级的祖先，则 fa[0][v] = fa[v]，且递推只需查两次上一层：

// 预处理（DFS 求出 dep / fa[0] 之后按 k 递推）
for v: fa[0][v] = parent(v)                  // 根的父结点记 0（不存在）
for k = 1 .. ⌊log2 n⌋:
    for v: fa[k][v] = fa[k-1][ fa[k-1][v] ]  // 先跳 2^(k-1)，再跳 2^(k-1)

// 查询
function lca(u, v):
    if dep[u] < dep[v]: swap(u, v)            // 保证 u 不浅于 v
    diff = dep[u] - dep[v]
    for k = K downto 0:                       // ① 深度对齐：按二进制位上跳
        if diff & (1 << k): u = fa[k][u]
    if u = v: return u                        // u 本来就是 v 的祖先
    for k = K downto 0:                       // ② 同步上跳：只在不等时跳
        if fa[k][u] ≠ fa[k][v]:
            u = fa[k][u]; v = fa[k][v]
    return fa[0][u]                           // 再跳一级即 LCA

为什么第二步要「从高位到低位、只在不等时跳」：维护的不变式是「跳完之后 u、v 仍然不同、仍然同深，且 LCA 依然是两者的祖先」。若 fa[k][u] ≠ fa[k][v]，说明 LCA 在这两点的更上方，此时一起上跳 2k 级绝不会越过 LCA；反之若相等（或同为不存在），说明这一跳可能恰好到达甚至越过 LCA，必须保留，改用更小的 k。从高位开始贪心，就把「跳到 LCA 的孩子那一层」的距离用二进制拼了出来，最后 fa[0][u] 恰好是 LCA。k 必须从大到小枚举，否则会少跳。

提示：另外两条通往 LCA 的路

① DFS 序 + ST 表（欧拉序 / 深度序列）：u、v 的 LCA 等于欧拉序中第一次出现 u、v 之间深度最小的结点，于是 LCA 化为 RMQ，预处理 O(n log n)、查询 O(1)，支持在线。② Tarjan 离线：DFS + 并查集，把 q 次询问一次遍历答完，O((n+q)·α(n))，但必须先知道全部询问，不能在线回答。③ 树链剖分也能在线求 LCA（O(log n)～O(log² n)），顺便还能做路径修改（本页不演示）。

倍增单次查询O(log n)—两段循环各把 k 从高位枚举到低位

应用与局限

应用：① 树上路径查询 / 修改——树上差分（路径加权、路径统计）、树链剖分把路径拆成链，都要先用 LCA 界定链端点；② 两点距离、树的直径与中心（配 dist[] 前缀和）；③ 虚树：把关键结点按 DFS 序排序后求相邻 LCA，压缩出只含关键信息与分叉的小树，是「关键点上的 DP」的标准降规模手段；④ 判定「u 是否是 v 的祖先」（lca(u,v)=u 或 DFS 序区间包含）、求 k 级祖先；⑤ 倍增本身是「跳跃指针」的一般技巧（自动机转移、O(n log n) 加速），也用于网络路由树、语法树 / DOM 的最近共同祖先查询。

局限：① 只对有根树有定义，一般图上没有 LCA（要先化成 DFS 树 / 生成树，答案与原图未必相符）；② 倍增表是 O(n log n) 空间，n 极大时可换 O(1) 查询的 ±1RMQ 或 Bender–Farach 方案；③ 树是动态（有连边、断边）时倍增失效，需要 LCT 或分块维护；④ 单次查询 O(log n)，若要 O(1)：离线用 Tarjan，在线用欧拉序 + ST 表。
