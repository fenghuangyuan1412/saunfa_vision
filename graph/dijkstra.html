Dijkstra 最短路

Dijkstra 算法求解非负权图上的单源最短路：从源点出发，每次从未确定的结点中取出「当前距离最小」的那个并定稿，再用它去松弛自己的出边。整个过程像水波一样由近及远地扩散，因此也被称为「标记设定（Label Setting）算法」。

算法原理

维护距离标号 d[]：源点 d[s]=0，其余初始化为 +∞；prev[] 记录最短树中的父结点，用于事后还原路径。核心只有两个动作：

① 取最小（贪心）：在所有尚未定稿的结点里取 d 最小者 u，此时 d[u] 已经是源点到 u 的最终最短距离，可以把 u 永久标记（定稿）。
② 松弛（relax）：对 u 的每条出边 (u,v,w) 尝试「绕道 u 是否更近」：

if (d[u] + w < d[v]) {
    d[v]    = d[u] + w;     // 发现更短的路，更新距离
    prev[v] = u;            // 记录前驱，最后用它回溯路径
}

正确性直觉：设 u 是未定稿结点中 d 最小者。任一从 s 到 u 且中途经过其它未定稿结点 x 的路径，长度必 ≥ d[x] ≥ d[u]——因为边权非负，多绕一段只会更远，不可能绕出更短的路。于是 d[u] 无法再被改进，可以放心定稿；归纳地，每个结点定稿时拿到的都是最短距离，且结点的定稿顺序恰好是 d 的非递减序。

procedure Dijkstra(s):
    for v in V: d[v] = +∞; prev[v] = NIL
    d[s] = 0;  S = ∅                    // S = 已定稿集合
    while |S| < |V|:
        u = 未定稿结点中 d 最小者         // 朴素实现：O(V) 线性扫描
        if d[u] = +∞: break             // 其余结点从 s 不可达
        S.add(u)                         // d[u] 从此定稿
        for (u, v, w) in E:              // 松弛 u 的每条出边
            if d[u] + w < d[v]:
                d[v] = d[u] + w
                prev[v] = u

三种「取最小」的实现

实现方式时间复杂度适用场景
朴素数组扫描O(V²)稠密图（E ≈ V²），实现最简、常数最小
二叉堆（优先队列）O((V+E) log V)稀疏图首选；常见写法是懒删除：入队 (d,v)，出队时若 d > d[v] 说明是过期记录，直接丢弃
配对堆 / Fibonacci 堆O(E + V log V)支持 O(1) decrease-key 即可达到此界；配对堆实测常数友好，Fibonacci 堆竞赛中极少手写

路径还原：从终点 t 出发沿 prev[] 一路回溯到 s，反序即得一条最短路径。最短路径未必唯一，prev[] 只保留最先取到的那条。若只关心 s → t 一个点对，t 一定稿就可以立即停止（本页演示为求全部可达点的最短路，会跑完所有可达结点）。

警告：Dijkstra 不能处理负权边

「取最小即定稿」完全依赖边权非负。出现负权边时，已定稿的结点仍可能被后来发现的「先绕远、再用负边收回来」的路径改进，而 Dijkstra 永不回头修改定稿结点，答案就会错。最小的反例只有 3 个结点：边为 A→B = 2、A→C = 5、C→B = −4（源点 A）。

轮次Dijkstra 的动作d[B]d[C]
初始d[A]=0∞∞
1定稿 A，松弛 A→B、A→C25
2取最小：2 < 5，B 定稿，此后不再更新2（定稿）5
3定稿 C，松弛 C→B：5 + (−4) = 1 < 2，但 B 已定稿，被忽略2 ❌5

真实最短距离是 d[B] = 1（路径 A→C→B），Dijkstra 给出 2。带负权的图请改用 Bellman-Ford / SPFA；若图中存在负环，最短路无定义（可无限绕环）。在正权图上，Dijkstra 的速度与稳定性仍是首选。

复杂度分析

指标量级说明
时间（朴素扫描）O(V²)定稿 V 次，每次线性扫最小 O(V)；松弛阶段总共扫过全部边 O(E)
时间（二叉堆优化）O((V + E) log V)每条边至多引起一次入队，出入队 O(log V)；稀疏图（E = O(V)）即 O(V log V)
时间（配对堆 / Fibonacci 堆）O(E + V log V)理论最优；均摊意义下的 decrease-key 代价
空间O(V + E)邻接表 + d[] + prev[] + 定稿标记 + 堆
边权要求必须非负；零权边无影响，出现负权边结果错误

应用与局限

应用：路网导航与地图最短路（距离天然非负）、OSPF 等链路状态路由协议、正权单源最短路类题目，以及若干扩展：

  • 次短路：把状态扩为 d[v][0/1]（最短、次短），松弛时同时维护两层并允许同点重复入队，跑满 2V 次定稿即可。
  • 分层图最短路：把「已经使用过几次免费/打折机会」作为新的一维，构造 V × (k+1) 个结点，跨层边权可为 0（仍非负），照常跑 Dijkstra。
  • A* 搜索：优先队列的键换成 f(v) = d[v] + h(v)，其中启发函数 h 是「到终点的距离下界」（如欧氏直线距离）。h 可采纳时结论仍最优，但扩展结点数显著减少，是地图与游戏中的标准做法。
  • Dijkstra 与 BFS / 01-BFS 的关系：边权全为 1 时退化为 BFS（队列天然有序）；边权只有 0 和 1 时用双端队列 deque 可以做到 O(V+E)。

局限：① 不支持负权边（见上方反例）；② 属单源算法，多源最短路要么反复跑（堆优化 O(V(V+E)log V)），要么改用 Floyd（O(V³)，适合 V ≤ 400 且需要任意两点答案）；③ 稠密图上堆的 log 开销可能不如朴素 O(V²)；④ 需要显式建图，隐式巨大状态空间要用哈希表存 d[]，此时常数明显上升。
