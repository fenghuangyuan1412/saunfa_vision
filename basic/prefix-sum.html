前缀和 & 差分

前缀和与差分是一对互逆技巧：前者用 O(n) 预处理把「区间和查询」降到 O(1)；后者用两次单点修改把「区间加」降到 O(1)，再靠一次前缀和还原原数组。二者都不需要复杂数据结构，是竞赛与工程中最常用的高效手段。

算法原理

前缀和：约定数组下标从 1 开始，定义 s[i] = a[1] + a[2] + … + a[i]（s[0] = 0）。递推式为 s[i] = s[i-1] + a[i]。于是任意闭区间的和：

sum(l, r) = a[l] + … + a[r] = s[r] − s[l − 1]     // 预处理 O(n)，单次查询 O(1)

之所以能相减，是因为 s[r] 与 s[l-1] 的公共前段 a[1..l-1] 被完整抵消，剩下恰是 a[l..r]。

二维前缀和（容斥）：设 s[i][j] 为以 (1,1) 为左上角、(i,j) 为右下角的子矩形元素和，则

s[i][j] = a[i][j] + s[i-1][j] + s[i][j-1] − s[i-1][j-1]      // 建表
sum(矩形 (x1,y1)..(x2,y2))
      = s[x2][y2] − s[x1-1][y2] − s[x2][y1-1] + s[x1-1][y1-1]  // 查询（容斥）

建表时左上块被加了两次故减去一块；查询时两个外接矩形都含 (x1-1, y1-1) 块，减了两次故加回一次。

差分：定义 d[i] = a[i] − a[i-1]（d[1] = a[1]），则 a[i] = d[1] + … + d[i]，即差分是前缀和的逆运算。要给 a[l..r] 整体加 v，只需：

diffAdd(l, r, v):
    d[l] = d[l] + v           // [l, n] 全部抬高 v
    d[r + 1] = d[r + 1] − v   // 从 r+1 起把多出的 v 收回
    // 需要新 a 时再做一次前缀和：a[i] = a[i-1] + d[i]
备注：互为逆运算

把「差分」看作离散版本求导，「前缀和」看作积分：prefix(diff(a)) = a，diff(prefix(a)) = a。因此「多次区间修改 + 最后统一查询」的标准套路是：全部修改打在差分数组上（每次 O(1)），最后一次前缀和还原（O(n)），总代价 O(n + m) 而不是 O(n·m)。

复杂度分析

指标量级说明
最优时间复杂度O(n + m)建表 O(n) + m 次 O(1) 查询；同样工作量朴素做法需 O(n·m)
平均时间复杂度O(n + m)耗时只取决于规模与操作次数，与数据内容无关
最坏时间复杂度O(n + m)无论区间长短，建表都是 O(n)、查询都是 O(1)
单次建表O(n)一次线性扫描 s[i] = s[i-1] + a[i]
单次区间查询O(1)朴素做法需累加 r-l+1 项（最坏 O(n)）
单次区间加（差分）O(1)只改 d[l] 与 d[r+1]；直接改 a 需 O(r-l+1)
空间复杂度O(n)一维；二维前缀和为 O(nm)，需注意内存上限

应用与局限

常见应用：区间和 / 区间平均查询、二维前缀和求子矩形和（公式见上，用于图像积分图、区域染色统计）、差分数组处理「多次区间投票 / 覆盖次数统计」（如公交占用区间、时间轴事件叠加）、差分建树与树上差分（把路径加拆成两个端点 + LCA 的 4 次点修改）、高精度 / 多项式中的差分表。判定「能否使用前缀和」的关键是运算存在逆元：减法可抵消，故求和可以；求最大值没有逆运算，故 max 区间不能用前缀和（应改用 ST 表，见 倍增）。

局限：① 前缀和是静态结构，数组单点修改会让后续所有 s[i] 失效（需 O(n) 重建），动态场景改用树状数组或线段树；② 前缀和可能溢出，n 与元素值较大时用 64 位整数或取模；③ 差分只能处理「区间加」等可线性叠加的修改，无法直接支持区间赋值、区间乘后求和等混合操作。
