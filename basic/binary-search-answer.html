二分答案

二分答案把「求满足某性质的最大 / 最小值」转化为对答案区间的二分：不直接构造最优解，而是不断猜测一个候选值 mid，用一个判定函数 check(mid) 回答「mid 行不行」，再依据单调性收缩区间。它是二分查找思想在连续（整数）值域上的推广。

算法原理

答案单调性：需要存在一个性质 P(x)，使得 x 变大时 P 只朝一个方向变化。典型形态是「若 x 可行，则所有 y > x 都可行」——可行值构成一个后缀 [x*, +∞)，于是求「最小可行值」等价于求第一个使 P 为真的位置，可以二分。

function binarySearchAnswer(lo, hi, check):    // 求最小可行值，check 随 x 增大由假变真
    ans = -1
    while lo <= hi:
        mid = lo + ((hi - lo) >> 1)
        if check(mid):                 // mid 可行 → 记录并尝试更小
            ans = mid; hi = mid - 1
        else:                          // mid 不可行 → 必须更大
            lo = mid + 1
    return ans                          // [lo, hi] 收缩结束时 ans 即最小可行值

本页的问题设定：给长度 n = 8 的非负数组 a，把它切成最多 k 个连续段（不能重排），最小化「各段和的最大值」。判定函数 check(x) = 「是否存在一种切法使每段和都不超过 x」，用贪心实现：从左到右扫描，当前段塞不下就立刻切一刀——这样得到的段数 cnt(x) 是最少的可能段数。于是：

  • check(x) 等价于 cnt(x) ≤ k；
  • x 越大越容易塞下，cnt(x) 单调不增，故 check 关于 x 单调（假 → 真），满足二分前提；
  • 上下界：lo = max(a)（任何一段至少要装下最大元素），hi = sum(a)（整段不切）。答案必在 [lo, hi] 内。

与二分查找的区别：二分查找在已排序的数组下标上折半、比较对象是数组元素；二分答案在值域上折半、比较对象是判定函数的真假，数组本身是否有序无关紧要，关键是判定函数的单调性。

提示：收缩方向的两种写法

求最小可行值（可行后缀）：check(mid) 为真时收缩右界 hi = mid - 1（并记录 ans = mid），为假时 lo = mid + 1。
求最大满足值（满足前缀，如「最远能走多远」）：方向正好相反——条件为真时 lo = mid + 1 并记录 ans = mid，为假时 hi = mid - 1。
两种写法都可以统一成「while lo < hi + 半开区间」模板：求最小可用 hi = mid，求最大可用 lo = mid 并令 mid = (lo + hi + 1) >> 1（上取整，否则 lo == hi - 1 时区间不缩小而死循环）。无论哪种模板，初始化、循环条件、收缩三处必须自洽。最后强调一次：check 必须单调，否则二分给出的不是答案而是错误——不确定时先暴力验证。

复杂度分析

指标量级说明
最优时间复杂度O(n log Σa)二分轮数由值域宽度决定，与输入顺序无关
平均时间复杂度O(n log Σa)每轮 check 线性扫描 n 个元素
最坏时间复杂度O(n log Σa)轮数为 ⌈log₂(hi − lo + 1)⌉；本页 Σa ≤ 8×9 = 72，故至多 7 轮。32 位值域（如 Σa ≤ 10⁹）时约 31 轮，即 31n
空间复杂度O(1)只用 lo / hi / mid 与几个累加变量（记录方案则 O(n)）

应用与局限

适用题型：「最小化最大值 / 最大化最小值」（本路的切段、aggrocows 牛舍间距、砍树 / 切绳长度）、可行的时间开销与速率上限（如 K 小时内吃香蕉的最慢速度）、任何「阈值越大越容易满足」的判定。共同点：答案可判定、判定单调、判定代价可接受。

局限：① 只给数值，不直接给出构造方案——若需输出具体切法，须再跑一次 check(answer) 的贪心把边界还原（本页最后一步正是这么做的）；② 若 check 不单调（例如带负数的切段问题），二分彻底失效，需改用 DP 等其它手段；③ 值域很大且精度为实数时，整数二分要改为按 eps 收敛的实数二分，并控制迭代次数（通常固定 60~100 轮）避免浮点误差导致死循环。
