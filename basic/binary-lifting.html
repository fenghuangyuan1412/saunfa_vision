倍增

倍增（Binary Lifting）是用 2 的幂次作为步长来加速跳转与区间合并的技巧：预先算出「一步走 2⁰, 2¹, 2², …」的结果，任何距离 d 都能拆成不超过 ⌊log₂d⌋ + 1 个 2 的幂之和，于是把 O(n) 次逐步跳转压缩为 O(log n) 次。

算法原理

设 f[k][i] 表示「从位置 i 出发，按某个可叠加的关系走 2^k 步得到的结果」。由于 2^k = 2^(k-1) + 2^(k-1)，「走 2^k 步」等价于「先走 2^(k-1) 步，再从中点再走 2^(k-1) 步」，得到通用递推：

f[0][i] = 基础值(i)                                // 走 1 步（长度 1 的区间）
f[k][i] = merge( f[k-1][i], f[k-1][i + 2^(k-1)] )   // 两个长度 2^(k-1) 的块拼成长度 2^k

ST 表（Sparse Table）是它在「区间最值」上的实例：f[k][i] = max(a[i..i+2^k−1])，即 merge = max、i + 2^(k-1) 是右半块的起点。

buildST(a[1..n]):
    for i = 1 to n: f[0][i] = a[i]
    for k = 1 while 2^k <= n:
        for i = 1 to n - 2^k + 1:
            f[k][i] = max(f[k-1][i], f[k-1][i + 2^(k-1)])

queryMax(l, r):
    len = r - l + 1
    k = floor(log2(len))          // 不超过 len 的最大 2 的幂
    return max(f[k][l], f[k][r - 2^k + 1])   // 两个长度为 2^k 的区间首尾重叠即可覆盖 [l, r]

查询用两个长度为 2^k 的区间：左端锚在 l，右端锚在 r。因为 2^k ≤ len < 2^(k+1)，两段之和 2^(k+1) > len，必然首尾相接甚至重叠，所以 [l, r] 被完整覆盖，取两次 max 即得答案。这种「允许重复覆盖」正是 ST 表只能用于可重复贡献（idempotent，op(x, x) = x）运算的原因。

其它倍增应用：树上跳祖先（fa[k][u] = fa[k-1][fa[k-1][u]]，配合深度对齐求 LCA）、快速幂（x^(2^k) 递推，把 n 次乘法降到 O(log n)）、二进制分组背包、序列跳转（如「走 K 步落在哪」的函数倍增）。

注意：ST 表只适用于可重复贡献运算

可重复贡献指 op(x, x) = x 且结合律成立：max、min、按位与、按位或、gcd 都满足；区间和不满足，因为重叠部分会被计入两次。反例：a = [1, 2, 3, 4]，仿照 ST 表用「两个长度 2 的块」查 [1, 3]：k = ⌊log₂3⌋ = 1，两段为 f[1][1] = 1 + 2 = 3 与 f[1][2] = 2 + 3 = 5，相加得 8，而真值 1 + 2 + 3 = 6——下标 2 的值 2 被重复计入。若把运算换成 max：max(3, 5) = 3（对块取 max 后 max(max(1,2), max(2,3)) = 3）依然正确，因为重复的 2 不改变结果。区间和请改用前缀和（见 前缀和 & 差分），需要「修改 + 查询」并存时用树状数组或线段树。

指标量级说明
最优时间复杂度O(n log n + m)预处理一次 + m 次 O(1) 查询；朴素做法为 O(n·m)
平均时间复杂度O(n log n + m)建表格数与查询次数固定，与数据分布无关
最坏时间复杂度O(n log n + m)同上；若数据有修改则需重建，重建代价仍是 O(n log n)

应用与局限

应用：静态区间最值（RMQ）、树上倍增求 LCA——用 fa[k][u] 表示 u 的 2^k 级祖先，先把两点深度对齐再同步上跳，单次查询 O(log n)，详见本站 LCA 页；快速幂把指数按二进制拆分，x^n 只需 O(log n) 次乘法；以及「走 K 步」类跳转（如函数迭代、倍增求第 K 小祖先）。字符串中也有倍增思想（如后缀数组的 rk 双关键字排序按长度 1, 2, 4, … 逐步加倍）。

局限：① 表一旦建好就不支持修改，任何单点改动会让 O(log n) 个区间失效，动态问题请用线段树；② 只适用于可重复贡献运算（见上方警告框）；③ O(n log n) 空间在 n 很大、层数多（如二维 ST 表）时容易超内存；④ 需要 ⌊log₂len⌋ 时通常预置 lg[] 数组，避免每次调用浮点 log 带来的精度误差（Math.floor(Math.log2(8)) 这类边界值应实测校验或改查表）。
