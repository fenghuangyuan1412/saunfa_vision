链表

单链表（Singly Linked List）是由一串节点组成的线性结构：每个节点保存一个值 val 和一个指向后继节点的指针 next，最后一个节点的 next 指向 NULL。与数组不同，链表的元素在内存中不必连续，靠指针串联，因此在已知位置前驱时插入/删除只需改一根指针，代价是访问第 k 个元素必须从头沿链行走。

算法原理

节点定义与五类基本操作（均以「值 + next」的节点为单元）：

struct Node {
    int  val
    Node next    // 指向后继；尾节点的 next = NULL
}

insertHead(head, v):        // 头插 O(1)
    node = Node(v)
    node.next = head
    return node             // 新节点成为新的 head

insertTail(head, v):        // 尾插：先走到 NULL 前一个节点，O(n)
    cur = head
    while cur != NULL and cur.next != NULL:
        cur = cur.next
    if cur == NULL: return Node(v)     // 空表
    cur.next = Node(v)
    return head

delete(head, v):            // 删除首个值等于 v 的节点，O(n)
    if head != NULL and head.val == v:
        return head.next
    prev = head
    while prev != NULL and prev.next != NULL:
        if prev.next.val == v:
            prev.next = prev.next.next // 摘链
            return head
        prev = prev.next
    return head                        // 走到 NULL，未找到

find(head, v):              // 查找，O(n)
    k = 0
    cur = head
    while cur != NULL:
        if cur.val == v: return k
        cur = cur.next; k = k + 1
    return -1

删除与「在第 k 个位置插入」都需要拿到目标位置的前驱节点，这正是下面技巧的用武之地。

提示：哨兵头节点（dummy head）

操作真实头节点时要区分「插/删的是不是第一个」两种情况，代码啰嗦且易错。哨兵技巧：在链表最前面挂一个不存数据、仅作锚点的 dummy 节点，所有操作从 dummy 出发，那么任何节点（包括原头节点）都有前驱，删除统一写成 prev.next = prev.next.next，插入统一挂在某个 prev 之后，返回 dummy.next 即为新的链表头。反转链表、合并有序链表、快慢指针找中点等问题都因它省下大量特判。

复杂度分析

操作时间复杂度说明
头部插入O(1)新节点 next 指向旧 head 即可
尾部插入（无尾指针）O(n)必须沿 next 走到尾节点；维护尾指针可降为 O(1)
按位插入 / 删除O(n)定位前驱需要遍历；改接指针本身 O(1)
查找值 vO(n)无序链表只能线性扫描，最坏走完到 NULL
访问下标 iO(n)不支持随机访问，这是与数组的本质区别
空间复杂度O(n)每个节点额外一个 next 指针

应用与局限

链表适合「频繁在已知位置附近增删、不按下标访问」的场景：LRU 缓存用哈希表 + 双向链表实现 O(1) 的命中提升与逐出；约瑟夫环用循环链表自然模拟报数出局；快慢指针可在链表上判环、找中点与倒数第 k 个节点（Floyd 判圈，见 OI Wiki 链表页）。局限：无法二分与随机访问；每节点一个指针的额外空间与堆式分配带来的缓存不友好，使同样 O(n) 的遍历在实测中明显慢于数组。
