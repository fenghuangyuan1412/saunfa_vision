二叉搜索树

二叉搜索树（Binary Search Tree，BST）是一棵满足「左小右大」有序性的二叉树：任一结点的左子树中所有值都小于它，右子树中所有值都大于它。正是这条有序性，使得查找、插入都只需从根出发逐层下行比较，平均复杂度为 O(log n)。

算法原理

BST 的性质：对每个结点 x，若其左子结点存在则左子树全部键值 < x，右子树全部键值 > x。等价说法：中序遍历 BST 得到严格升序序列，这常用来检验一棵树是否是合法 BST。

查找：从根开始，把目标 v 与当前结点比较，小于则进左子树，大于则进右子树，相等即命中；走到空指针则不存在。插入：与查找同样的下行路径，走到空位时在那里挂上新结点，因此 BST 不存储重复值。

function find(node x, v):
    if x = nil: return FAIL        // 走到空指针
    if v = x.val: return x          // 命中
    if v < x.val: return find(x.left, v)
    else:         return find(x.right, v)

function insert(node x, v):
    if x = nil: return new Node(v)  // 空位生成新结点
    if v < x.val: x.left  = insert(x.left, v)
    else:         x.right = insert(x.right, v)
    return x

三种 DFS 遍历只在「访问根的时机」上不同：前序为 根→左→右，中序为 左→根→右，后序为 左→右→根。其中中序遍历 BST 输出升序，是 BST 的一张「身份证」。

procedure inorder(x):
    if x = nil: return
    inorder(x.left)
    visit(x)          // 中序：先左子树，再根，再右子树
    inorder(x.right)
警告：退化与平衡

BST 的形状完全由插入顺序决定。若按递增（或递减）顺序插入，树会退化成一条链，查找复杂度从 O(log n) 劣化为 O(n)。随机插入时期望高度约 2 ln n ≈ 2.3 log n，可以接受；但对最坏情况敏感的程序需要使用自平衡 BST（AVL、红黑树、Splay、Treap 等）来强制保持树高 O(log n)。参见 OI Wiki 数据结构总览 与 Treap。

应用与局限

BST 天然是有序集合的实现：支持前驱/后继、排名、按序遍历，是许多容器（如 C++ std::set 背后的红黑树）的抽象模型。「配合中序遍历判合法 BST」也是常见考点——一棵树合法当且仅当其中序序列严格升序。局限在于：不加平衡维护的普通 BST 对插入顺序极度敏感，最坏退化成链；工程与竞赛中通常直接使用平衡树或树状数组等替代品。
