Saunfa Vision

Saunfa Vision 是一个仿 OI-wiki 风格的开源算法讲解站点，面向 OI / ACM 学习者与算法入门者。每个算法一页，包含文字讲解、伪代码、可交互的分步可视化演示与复杂度分析。站点是纯静态页面，双击任意 HTML 即可在本地运行。

使用方式

进入任意算法页后，在「可视化演示」面板点击 ▶ 播放 自动演示，或用 下一步 / 上一步 逐帧研究；速度可调节，页面右侧（或底部）的说明行会给出每一步的具体含义。

基础算法

复杂度分析
大 O 记号与增长阶对比，看清 2ⁿ 与 n² 的差距有多大。
枚举
位掩码枚举全部子集，理解「穷举 + 剪枝」的边界。
模拟
约瑟夫环逐步维护状态：报数、出圈、幸存者。
递归 & 分治
汉诺塔 + 递归调用栈可视化，看清 2ⁿ−1 次移动从何而来。
贪心
区间调度贪心，以及贪心为什么会错的反例。
前缀和 & 差分
O(n) 预处理换 O(1) 区间查询，差分是它的逆运算。
二分答案
在答案空间二分 + 贪心判定，解决「最小化最大值」。
倍增
ST 表逐层填表，O(n log n) 预处理换 O(1) 区间最值。
构造
Havel–Hakimi 定理：由度数序列判定并构造简单图。

排序算法

冒泡排序
相邻比较与交换，O(n²) 稳定排序，提前退出优化。
快速排序
Lomuto 分区递归，平均 O(n log n) 的不稳定原地排序。
归并排序
分治合并，稳定的 O(n log n) 排序，需 O(n) 辅助空间。

查找算法

二分查找
有序数组上 O(log n) 折半定位，含边界收缩与防溢出写法。

动态规划

数字三角形
DP 入门：状态定义、转移方程、自底向上填表与路径回溯。
最长上升子序列
「以 i 结尾」的状态设计，O(n²) 与 O(n log n) 两种做法。
最大子段和
Kadane 算法：要么接上前面，要么从我重新开始。
0/1 背包
二维填表 + 一维滚动数组为何必须逆序枚举容量。
完全背包
与 0/1 只差一行：转移来自本行，正序枚举即允许重复选。
最长公共子序列
二维网格转移与对角线回溯，子序列与子串的区别。
编辑距离
插入 / 删除 / 替换三来源取最小，回溯出具体操作序列。
区间 DP：石子合并
按区间长度枚举，分割点取最优；环形与四边形不等式优化。

数据结构

栈
LIFO 结构动手实验：入栈、出栈、括号匹配与递归的关系。
链表
单链表头/尾/按位插删与遍历动画，哨兵节点技巧。
二叉搜索树
插入与查找路径可视化，三种 DFS 遍历与退化问题。

图论

广度优先搜索
队列逐层扩展，网格迷宫求无权最短路，队列实时可见。
深度优先搜索
一路走到底再回溯，调用栈实时可见，理解与 BFS 的差异。
Dijkstra 最短路
贪心定稿 + 松弛，堆优化 O(E log V)，不能处理负权。
Bellman-Ford 与 SPFA
队列优化松弛，支持负权边与负环检测。
Floyd 多源最短路
中转点 k 必须在最外层的 O(n³) 三重循环。
最近公共祖先 LCA
倍增表预处理 + 两步上跳查询，O(log n) 一次。

字符串

Trie 字典树
按字符下行的插入 / 查询 / 前缀计数，节点与边实时生成。
KMP 模式匹配
next 数组逐步求解，主串指针永不回退的匹配过程。
