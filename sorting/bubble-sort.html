冒泡排序

冒泡排序（Bubble Sort）是一种简单的比较排序算法。它重复地遍历数组，每次比较相邻的两个元素，若顺序错误就交换它们。每一轮遍历都会把当前未排序部分的最大值「浮」到末尾，如同气泡上浮，因此得名。

算法原理

对长度为 n 的数组，外层循环进行至多 n-1 轮；第 i 轮从下标 0 到 n-i-1 依次比较相邻元素，逆序则交换。一轮结束后，末尾的 i 个元素已经就位。若某一轮没有发生任何交换，说明数组已经有序，可以提前结束。

procedure bubbleSort(A[0..n-1]):
    for i = 1 to n - 1:
        swapped = false
        for j = 0 to n - i - 1:
            if A[j] > A[j+1]:
                swap(A[j], A[j+1])
                swapped = true
        if not swapped:
            break   // 已经有序，提前退出
提示

冒泡排序是稳定排序：相等元素不会交换，相对顺序保持不变。

复杂度分析

指标量级说明
最优时间复杂度O(n)数据已有序时，仅一轮扫描即可退出
平均时间复杂度O(n²)约进行 n²/4 次比较与交换
最坏时间复杂度O(n²)数据完全逆序
空间复杂度O(1)原地排序，仅需常数辅助变量
稳定性稳定相等元素不交换

应用与局限

冒泡排序实现简单、原地、稳定，但 O(n²) 的期望性能使它不适合大规模数据。教学之外，它偶尔出现在需要「限制交换次数」或代码必须极简的场景；工程中同等需求一般选择插入排序。OI 比赛中几乎不会直接用它排序，但它是不等式相邻交换证明（如逆序对分析）的经典模型。
