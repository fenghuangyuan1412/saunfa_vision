区间 DP：石子合并

石子合并是区间 DP（Interval DP）的标准入门题：n 堆石子排成一排，每次只能合并相邻的两堆，代价是这两堆的石子数之和，把所有石子并成一堆的最小总代价是多少。它的状态用「区间端点」描述，转移枚举最后一次合并的分界点，因此必须按区间长度从小到大填表——这一顺序是所有区间 DP 的共同命门。

算法原理

状态定义：dp[l][r] = 把第 l 堆到第 r 堆合并成一堆的最小代价。边界 dp[i][i] = 0（单堆不需要合并）。

考虑最后一次合并：区间 [l, r] 一定先各自合并成了两堆，形式为 [l, k] 与 [k+1, r]（l ≤ k < r），再把这两堆合起来，本步代价恰好是这两堆的石子总数，也就是 sum(l..r)。枚举分界点取最小：

dp[l][r] = min over k∈[l, r-1] ( dp[l][k] + dp[k+1][r] ) + sum(l..r)

区间和用前缀和 s[i] = a[1] + … + a[i] 做到 O(1) 查询：sum(l..r) = s[r] - s[l-1]。同时记录取到最小值的 k（bestK[l][r]），最后自顶向下递归展开即可还原出括号化方案 / 合并顺序。

填表顺序是关键：dp[l][r] 依赖的 dp[l][k] 和 dp[k+1][r] 都是更短的区间，所以外层必须枚举长度 len = r - l + 1 从 2 到 n，内层枚举左端点 l、再枚举分界点 k。若按 l 从大到小、r 从小到大写，也满足「子区间先算完」，同样正确；但绝不能用「一行一行」的顺序。

procedure stoneMerge(a[1..n]):
    s[0] = 0
    for i = 1 to n: s[i] = s[i-1] + a[i]        // 前缀和，O(1) 求区间和
    for i = 1 to n: dp[i][i] = 0
    for len = 2 to n:                           // 按区间长度从小到大
        for l = 1 to n - len + 1:
            r = l + len - 1
            dp[l][r] = +∞
            for k = l to r - 1:
                cost = dp[l][k] + dp[k+1][r] + (s[r] - s[l-1])
                if cost < dp[l][r]:
                    dp[l][r] = cost
                    bestK[l][r] = k             // 记住分界点，用于重建方案
    return dp[1][n]

procedure printOrder(l, r):                     // 递归重建合并顺序
    if l == r: return "a[" + l + "]"
    k = bestK[l][r]
    printOrder(l, k);  printOrder(k+1, r)
    emit("合并区间 [" + l + ", " + r + "]，代价 " + (s[r] - s[l-1]))
    return "(" + printOrder(l, k) + " " + printOrder(k+1, r) + ")"
提示：为什么「最后一次合并」是好状态

区间 DP 的通用套路是给区间加一个「最后一步」的语义：[l, r] 的最后一次合并把区间分成左右两段，且这个划分点 k 与「中间过程如何合并」无关，于是子问题彼此独立，最优子结构成立。同样的骨架直接搬到矩阵链乘（把 sum(l..r) 换成 p[l-1]·p[k]·p[r]）、多边形三角剖分（枚举包含顶点 r 的三角形）、能量项链（环形 + 三元代价）。

复杂度分析

指标量级说明
最优时间复杂度O(n³)状态 O(n²) 个，每个状态枚举 O(n) 个分界点；与数据无关
平均时间复杂度O(n³)三层循环 len × l × k，约 n³/6 次转移
最坏时间复杂度O(n³)同上；不加优化的区间 DP 普遍是这一阶
空间复杂度O(n²)dp 与 bestK 各一张上三角表；前缀和 O(n)
环形版本O((2n)³) = O(n³)拆环成 2n 长链后枚举长度为 n 的区间，常数约为 8 倍
注意：环形合并与四边形不等式优化

环形石子合并（n 堆围成一圈，任意位置都可「剪开」）不能直接套链式 DP，因为不存在固定的 1 号位。标准做法是拆环成链：把数组复制一份接在自己后面得到长度 2n 的链，在这条链上做区间 DP，答案取 min over i ( dp[i][i+n-1] )（枚举「断开的那条边」）。若求最大代价则把 min 换成 max。注意此时区间长度上限是 n，不能填到 len > n，否则会把同一堆算两次。

四边形不等式优化：当区间代价函数 w(l, r) 满足四边形不等式（w(a,c)+w(b,d) ≤ w(a,d)+w(b,c)，对 a ≤ b ≤ c ≤ d）与区间单调性（w(b,c) ≤ w(a,d)），可以证明 dp 也满足四边形不等式，从而最优分界点 bestK[l][r] 关于 l、r 单调：存在 bestK[l][r-1] ≤ bestK[l][r] ≤ bestK[l+1][r]。于是把内层 k 的枚举范围限制在这个窗口内，总复杂度降到 O(n²)；实现上常写成 k 从 bestK[l][r-1] 枚举到 bestK[l+1][r]。石子合并的 w(l,r) = sum(l..r) 恰好满足条件，因此可优化；而「任意带负数、代价函数不单调」的变形就不能直接用——优化前必须先验证单调性成立。

应用与局限

同一套「枚举最后一次分割」的骨架覆盖了一大类题：矩阵链乘（最小标量乘法次数，代价项换成三个维度相乘）、多边形三角剖分（枚举与某条边组成三角形的第三个顶点）、能量项链（环形 + 三元头尾能量相乘）、括号密码 / 凸多边形染色、统计子区间型问题（如「最长合法括号子串」「合并果子」的对偶版本）、以及最优二叉搜索树（其代价函数同样满足四边形不等式，可 O(n²) 优化）。凡「把一段区间劈成两半、两半独立求解再合并」的题目都属此家族。

局限：一是 O(n³) 的状态转移使可处理规模通常限制在 n ≤ 300 左右，需要靠四边形不等式或分治优化降阶；二是区间 DP 只对连续区间有效，「任意两堆合并」的合并果子问题应改用哈夫曼贪心（优先队列），强行套区间 DP 反而会得到错误答案——这正是「相邻约束」与「自由选择」的差别；三是需要输出方案时必须额外保存 bestK 表，内存翻倍。
