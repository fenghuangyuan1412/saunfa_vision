最大子段和

最大子段和（Maximum Subarray Sum）要求在一个序列中选出一段连续的非空子序列，使元素之和最大。它的 O(n) 解法就是著名的 Kadane 算法，也是「用一维滚动 DP 取代二维枚举」的典型示范。

算法原理

暴力做法枚举左右端点 (l, r) 共 O(n²) 段（配合前缀和仍是 O(n²)）。要降到 O(n)，必须找到只依赖「上一个位置」的状态：

  • 状态定义：dp[i] = 以 A[i] 结尾的最大子段和（A[i] 必须被选，且是这段的右端点）。
  • 转移方程：dp[i] = max(dp[i-1] + A[i], A[i]) —— 要么把 A[i] 接在「以 A[i-1] 结尾的最优段」后面，要么觉得前面是累赘，从 A[i] 重新开始。
  • 边界条件：dp[0] = A[0]（只有一个元素可取）。
  • 填表顺序：i 从左到右，一次线性扫描。
  • 答案位置：max(dp[0..n-1])，即扫描过程中历史最大值；右端点就是取到最大值的那个 i。
  • 方案回溯：转移时记录这一段从哪里开始（选择「重新开始」时起点就是 i），得到 start[i]；配合记录最优右端点即得区间 [start[bestR] .. bestR]。

注意「dp[i-1] + A[i] 与 A[i] 取较大」等价于判断 dp[i-1] > 0：前面的贡献是负的就不要。这就是 Kadane 算法的全部直觉。

procedure MaxSubarray(A[0..n-1]):                // Kadane：滚动一维，O(1) 空间
    best = A[0]; bestL = 0; bestR = 0
    cur = A[0]; curL = 0                         // cur = dp[i]，curL = 当前段左端点
    for i = 1 to n - 1:
        if cur + A[i] < A[i]:                    // 等价于 cur < 0
            cur = A[i]; curL = i                 // 从 A[i] 重新开始
        else:
            cur = cur + A[i]                     // 接上前一段
        if cur > best:
            best = cur; bestL = curL; bestR = i  // 记录历史最优及其区间
    return (best, bestL, bestR)

// 显式二维状态版本（便于理解「结尾」含义）
dp[0] = A[0]
for i = 1 to n - 1:
    dp[i] = max(dp[i-1] + A[i], A[i])
answer = max(dp[0 .. n-1])                       // 不是 dp[n-1]！
易错：全负数组必须返回最大负数，而不是 0

若把 cur、best 初始化成 0，则对 A = [-3, -1, -4] 会算出「最大子段和 = 0」——但 0 并不对应任何非空子段。正确写法是把初始值取为首元素：cur = best = A[0]，循环从 i = 1 开始；这样全负时答案是最大的那个负数（此处为 -1）。

只有当题目允许空子段（约定空段和为 0）时才应初始化为 0：把 best = A[0] 改成 best = max(0, A[0])（或等价地 cur = max(cur + A[i], 0) 并允许区间为空）即可，一行改动。做题时务必先确认「子段是否可以为空」，这是本题被 WA 的头号原因。

复杂度分析

指标量级说明
最优时间复杂度O(n)一次线性扫描，每个位置常数次运算
平均时间复杂度O(n)与数据分布无关
最坏时间复杂度O(n)不存在退化；分治写法才是 O(n log n)
空间复杂度O(1)滚动掉 dp[] 后只剩 cur / best / curL 等常数个变量
显式 dp 数组O(n)需要输出每步 dp[i] 或做变形（如分块）时保留

应用与局限

Kadane 的本质是「状态只保留以当前位置结尾的最优值」，这一套压缩手法可推广到一大类问题：

  • 最大 m 段子段和：状态加一维，dp[k][i] = 前 i 个元素取 k 段且第 k 段以 A[i] 结尾的最大和，转移分「A[i] 并入第 k 段」与「A[i] 另起一段」两支，O(nm) 可解（洛谷 P1115 的加强版、POJ 2479）。
  • 环形最大子段和：答案要么是普通最大子段和，要么是「总和 − 最小子段和」（即跨越首尾的那一段）；取两者较大，注意全负时需要特判，因为「总和 − 最小 = 空」不合法。最小子段和只需把 max 换成 min 再跑一遍 Kadane。
  • 二维版本：矩阵最大子矩阵和，枚举上下边界把列压成一维前缀和后跑 Kadane，复杂度 O(rows² · cols)（POJ 1050）。
  • 工程上用于序列显著性检测：把每个时刻的对数似然差作为权值，最大子段和即「最可能的一段变化区间」。

局限：Kadane 只适用于「连续」子段；若改成不要求连续的子序列，问题会变成「所有正数之和」（平凡）或加上其它约束后回到 LIS 那类 O(n²)/O(n log n) 模型。另外它求的是和的最大化，对「长度受限」「必须非空」「不允许全为负」等约束需要相应改写边界。
