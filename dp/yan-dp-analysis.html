闫式 DP 分析法

闫式 DP 分析法（也写作「闫氏 DP 分析法」，由 AcWing 创始人闫学灿在《算法竞赛进阶指南》与 AcWing 算法基础课中提出）把「列状态、推转移」这件最依赖灵感的事拆成两个固定动作：状态表示（化零为整，寻找共性）与状态计算（化整为零，寻找不同）。状态表示只回答两问——集合是什么、这个集合上求什么属性；状态计算只做一件事——把这个集合按最后一个关键决策划分成若干子集，做到不重不漏，每个子集的最值就是转移方程的一项。

本讲义用同一组数据把 01 背包与完全背包按这套流程各推一遍，并把「01 背包一维要逆序、完全背包要正序」这一常见口诀归回到集合划分本身：两个方程的差别只来自划分方式，循环顺序只是方程的直译。

算法原理

整套方法就是两张必答的表：

阶段要写出的内容自检标准
状态表示
化零为整，找共性		集合：f[i][j] 对应哪一整类方案——一句话讲清，如「只考虑前 i 件、总体积不超过 j 的所有选法」
属性：在这个集合里求什么——max / min / 计数 / 可行性，以及要不要记具体方案		所有合法方案都被某个状态覆盖（不漏）；同一方案尽量只落进一个子集（不重）
状态计算
化整为零，找不同		按最后一个关键决策把集合切成若干子集，每个子集去掉最后那一步后恰好是一个更小规模的状态 → 得到转移方程子集两两不交、并为原集合；方程右端每一项都是已经算出的状态
划分依据怎么选

挑一个「切完仍然自洽」的角度，通常是最后一件被处理的物品或最后一步操作。01 背包按「第 i 件选 / 不选」切两刀；完全背包按「第 i 种物品选 k 件」切成多刀。切完把最后放进去的物品拿走，剩下的正好是下标更小的状态——这就是最优子结构在集合语言下的写法。求最值时允许子集适度重叠（max 幂等），计数时不允许。

讲义一：01 背包（每件最多选一次）

状态表示

  • 集合：f[i][j] = 只从前 i 件物品中选、总体积 ≤ j 的全部选法。
  • 属性：这些选法中的最大总价值（max）。

状态计算：按「第 i 件选不选」划分成两个子集。

  • 子集 ①（不选 i）：方案全部落在「前 i-1 件、体积 ≤ j」里，最优值 f[i-1][j]。
  • 子集 ②（选 i）：先放入 i（占体积 v[i]、贡献价值 w[i]），剩余部分必须是「前 i-1 件、体积 ≤ j-v[i]」的最优选法，最优值 f[i-1][j-v[i]] + w[i]；仅当 v[i] ≤ j 时该子集非空。
f[i][j] = max( f[i-1][j],  f[i-1][j - v[i]] + w[i] )     // 第二项仅当 v[i] ≤ j
边界：f[0][j] = 0        答案：f[n][W]        来源：第 i-1 行

两项来源都在第 i-1 行：每件物品只能进一次方案，所以「选 i」这一支必须回到「还没考虑 i」的那一层取值。

讲义二：完全背包（每种可选任意多件）

状态表示与 01 背包只差一个量词：

  • 集合：f[i][j] = 只用前 i 种物品（每种件数不限）、总体积 ≤ j 的全部选法。
  • 属性：最大总价值（max）。

状态计算：按「第 i 种物品选了几件」划分，得到 k = 0, 1, 2, … 个子集：

f[i][j] = max over k ≥ 0, k*v[i] ≤ j  {  f[i-1][ j - k*v[i] ] + k*w[i]  }

这一项是 O(W) 长的，直接算会多一维。闫式的下一步是把 j 换成 j - v[i] 再写一遍并比较，让冗余的子集互相吸收：

f[i][j - v[i]] = max over k ≥ 0 { f[i-1][ j - v[i] - k*v[i] ] + k*w[i] }
               = max over k ≥ 1 { f[i-1][ j - k*v[i] ] + (k-1)*w[i] }      // 下标整体平移

两边同加 w[i]：
f[i][j - v[i]] + w[i] = max over k ≥ 1 { f[i-1][ j - k*v[i] ] + k*w[i] }   // 恰是 k ≥ 1 的那些子集

而 k = 0 的那个子集 = f[i-1][j]

合并 =>   f[i][j] = max( f[i-1][j],  f[i][j - v[i]] + w[i] )

关键差别一目了然：01 背包两支都来自上一行 f[i-1][*]，完全背包的第二支来自本行 f[i][j-v[i]]——本行左侧已经把「第 i 种再拿任意多件」的全部子集吸收进去了，所以只需一次比较。

一维滚动数组：循环方向是方程的直译
  • 01 背包：两支都要第 i-1 行的旧值。一维数组里若 f[j-v[i]] 已被本轮更新，等价于「第 i 件用了两次」。故 j 必须从大到小。
  • 完全背包：第二支要的正是本轮的 f[j-v[i]]（同种可重复）。故 j 必须从小到大。

口诀：01 倒，完全正。同一件物品，两种背包的差别只剩这一行循环方向。

可套用的书写模板

procedure yanDP():
    // 一、状态表示
    //     集合  f[i][j] : ……的 所 有 方 案          <- 一句话，不许含糊
    //     属性        : 这些方案的 max / min / 数量 / 可行性
    // 二、状态计算
    //     找"最后一个关键决策"，把集合切成 不重不漏 的子集
    for i = 1 .. n:
        for j = 0 .. W:
            f[i][j] = 边界值                          // 空集：f[0][j] = 0
            for 每个子集 s:
                f[i][j] = max(f[i][j], 用更小状态表达的 s 的最优值)
    // 三、答案位置 = f[n][W]；回溯方案靠"这个值来自哪个子集"倒着走
    return f[n][W]

落笔时先答四问：集合是什么？属性求什么？按什么划分？答案落在哪个状态？四问答完，方程基本就写完了。

W 是数值而非输入长度，因此 O(nW) 属伪多项式：容量按二进制写完，输入规模只有 log W，时间相对输入长度是指数级。这正是背包「有 DP 解法」与「NP-hard」并不矛盾的原因。

应用与局限

  • 同一套划分推出整族背包：多重背包（第 i 件最多 s[i] 次，按 k = 0..s[i] 划分，再二进制拆分或单调队列优化）、分组背包（每组至多一件，按「本组选哪件」划分，循环为 i → j → k 且 j 逆序）、混合背包（每件按类型套对应方程）、有依赖的背包（在树上做「选父则可选子」的划分）。
  • 路径类同构：数字三角形、网格路径的「集合 = 到达 (i,j) 的全部路径，属性 = max，划分 = 最后一步从左下还是右下上来」，与 01 背包的划分结构完全一致，见 数字三角形。
  • 局限一：划分必须不重不漏。求最值时子集适度重叠无碍（max 幂等），计数型 DP 会把同一方案算多次，必须保证切分唯一或补容斥。
  • 局限二：状态表示写错，方程再对也白算。最常见的是把「总体积不超过 j」与「恰好体积为 j」混用——后者边界要初始化成 -∞，且答案是 min over j 而非 f[n][W]。
  • 局限三：W 过大时不可用。W > 10⁵ 量级需换成对偶状态（按价值开数组求最小体积），或退到贪心、搜索、近似算法。
